Overview
This application is a full-stack personal finance and expense tracking management system built using the MERN stack architecture. It provides an intuitive interface for users to monitor daily transactions, manage personal finances, maintain separate logs for incomes and expenses, visualize overall financial trends through interactive analytical charts, and export account summaries.

Key Features

- User Authentication System: Secure registration and login modules with password hashing and session management.
- Comprehensive Transaction Management: Full CRUD operations allowing users to add, update, search, filter, and delete income and expense records.
- Categorization and Logging: Ability to classify transactions by specific payment methods, source of income, and expense categories for better organization.
- Financial Analytics and Data Visualization: Visual representations of spending behavior, monthly statistics, and income versus expense comparisons powered by Recharts.
- File Export Capability: Support for exporting transaction history and financial summaries into downloadable Excel files.
- Responsive Design: User interface optimized for smooth interaction across different desktop and mobile screen layouts.

Tech Stack and Tools

- Frontend Framework: React.js with Vite build tool
- Styling and UI Components: Tailwind CSS and Lucide React Icons
- Charting Library: Recharts
- Backend Environment: Node.js with Express.js web framework
- Database Management: MongoDB managed via MongoDB Compass
- Version Control: Git and GitHub

System Prerequisites

- Node.js runtime environment (v14 or higher)
- npm package manager
- MongoDB Community Server running locally with MongoDB Compass client connection at mongodb://localhost:27017

Installation and Local Deployment Guide

Step 1: Backend Setup
Navigate into the backend directory:
cd backend

Install required server dependencies:
npm install

Start the backend API server:
npm start

The server will initialize on port 4000 at http://localhost:4000

Step 2: Frontend Setup
Open a separate terminal session and navigate into the frontend directory:
cd frontend

Install required client dependencies:
npm install

Launch the frontend development server:
npm run dev

Access the user interface via the local server URL provided in the terminal output.
